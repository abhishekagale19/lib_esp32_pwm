# lib_esp32_pwm

Dual LED Fade with ESP32PWMA simple demonstration of standard Arduino-style analogWrite() functionality on an ESP32 using the ESP32PWM library. This project fades the onboard LED on and off while simultaneously driving a second external LED in complementary reverse fading.OverviewUnlike standard Arduino boards (like the UNO), the ESP32 handles Pulse Width Modulation (PWM) through flexible hardware LED Control (LEDC) channels. By leveraging the ESP32PWM library, this sketch abstracts away manual channel configuration, allowing you to use familiar syntax to smoothly transition LED brightness across multiple pins.Key BehaviorsPrimary Channel (GPIO 2): Fades up from 0 to 255 (0% to 100% duty cycle) and back down.Secondary Channel (GPIO 4): Fades inversely from 255 to 0 (100% to 0% duty cycle) simultaneously.Serial Telemetry: Outputs a status log ("cycle done") to the Serial Monitor at 115200 baud upon completing each fade cycle.Hardware RequirementsComponentQuantityNotesESP32 Development Board1Any standard ESP32 variant (e.g., ESP32 DevKit v1)External LED1Any color (3mm or 5mm)Current Limiting Resistor1$220\ \Omega$ to $330\ \Omega$ recommendedBreadboard & Jumper Wires—For prototyping external hardware
